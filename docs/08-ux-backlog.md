# 双端使用体验待完成清单

本清单维护已确认、尚未完成的体验改进及其验收条件，是后续扩展和完成任务的统一入口。这里的目标均为待实现要求，不代表当前软件已经具备这些行为。当前起点为 Windows 0.3.2 修复候选与 Android 0.3.1。

## 维护方式

- 使用稳定编号 `UX-001` 起连续增加；新增任务从 `UX-011` 继续，不因排序或完成而重编号。
- 下方复选框为任务完成状态的唯一来源。未勾选项默认待完成；进行中或等待验证时，在对应详情注明状态和未完成条件。
- 实现前先更新对应端规格，明确状态、资源所有权、失败路径及界面变化，再开发。保持[双端界面规范](06-ui-style-guide.md)，优先复用现有布局、控件、状态文字及短提示。
- 只有代码、必要回归、规定的实机核验和相关规格均完成后才能勾选；证据不足时保留未完成，并写清尚缺的验证。
- 完成项保留简短勾选记录，详情收敛为当前实现规格和验收入口链接；不累计开发经过、命令输出或历史截图。原始证据存入忽略的 `artifacts` 或 CI 产物。
- 删除或取消的需求移出当前清单，编号不复用；变更历史由 Git 保存。新增发现须区分已确认问题、条件性风险和待验证场景，不将推测直接登记为确定故障。

## UX-001 · 失效播放设备

**当前缺口**：已保存的输出端点不在活跃设备列表时，名称回落为“跟随电脑默认输出”，但配置仍保留旧端点 ID。界面与播放链不一致。

**完成标准**：明确区分“跟随系统默认”“所选设备可用”“所选设备不可用”。不可用时提供重新选择或明确切换到默认输出的操作，不误报已完成切换，不修改 Windows 全局默认设备。

**验收**：选定声卡后拔出、重新插入、改变系统默认设备、选择其他设备以及重启应用；核对设置、主界面、实际输出与日志一致，共享/独占两种模式均覆盖。

**涉及位置**：[设备名称缓存与设置](../src/SinkLite/Ui/MainWindow.cs)、[输出端点创建](../src/SinkLite/Core/WasapiOutputDevice.cs)。实现规格写入[电脑端规格](03-pc-implementation.md)。

## UX-002 · 取消连接与重连

**当前缺口**：底层已有明确断开能力，手机界面没有直接取消查找或停止自动重连的入口；开始/停止发送与断开连接的语义尚未完整呈现。

**完成标准**：在现有状态卡或操作区提供对应状态下的取消/断开操作。取消后停止该目标的探测和恢复，迟到事件不能重新建立连接；停止发送、断开电脑、结束采集授权的行为分别定义，并与通知、悬浮窗及资源释放一致。

**验收**：首次查找、握手、传输验证、恢复退避及正在发送时分别操作；覆盖连续点击、取消后立即选另一台电脑、迟到回复和返回后台，不残留恢复任务或采集资源。

**涉及位置**：[手机界面](../android/app/src/main/java/com/blueaudiosink/sender/ui/SenderScreen.kt)、[应用控制器](../android/app/src/main/java/com/blueaudiosink/sender/core/LinkController.kt)、[会话管理](../android/app/src/main/java/com/blueaudiosink/sender/net/bas2/SessionCoordinator.kt)。实现规格写入[手机端规格](04-android-implementation.md)。

## UX-003 · 后台操作与退出交接

**当前缺口**：部分设置在后台任务完成后的 UI 回调中才提交。退出先禁用 UI 回调、关闭设置写入器，再等待任务，可能丢失最终配置和操作结果。

**完成标准**：定义统一退出顺序，明确完成、取消及失败的处理者。成功操作的最终配置在写入器关闭前提交；取消不留下半完成状态。退出等待有边界，窗口销毁后不再依赖 UI 回调完成关键保存。

**验收**：用可控慢任务覆盖修改日志目录、保留期和输出设备后立即关闭或从托盘彻底退出；覆盖成功、失败、取消和重复退出。重开后结果一致，不发生死锁或销毁后回调。

**涉及位置**：[窗口退出](../src/SinkLite/Ui/MainWindow.cs)、[后台动作](../src/SinkLite/Ui/BackgroundActions.cs)、[日志设置](../src/SinkLite/Ui/LogSettings.cs)、[设置写入器](../src/SinkLite/Platform/SettingsWriter.cs)。实现规格写入[架构](01-architecture.md)与[电脑端规格](03-pc-implementation.md)。

## UX-004 · 忙碌范围与操作反馈

**当前缺口**：通用后台任务复用模式切换标记，导致不冲突的导航也被禁用；部分操作统一显示“正在切换模式”，与实际动作不符。

**完成标准**：分别表达模式切换、连接启停、设备切换和刷新等动作，只禁用会冲突的操作，保留可用导航。按动作显示真实阶段；定义超时和适用的取消路径，失败后恢复可操作状态。

**验收**：注入慢设备枚举、慢连接关闭及操作失败，核对鼠标、键盘、页面查看、提示文字和控件状态；重复请求不能重复执行，旧完成事件不能覆盖新操作。

**涉及位置**：[后台动作](../src/SinkLite/Ui/BackgroundActions.cs)、[命中、键盘与状态绘制](../src/SinkLite/Ui/MainWindow.cs)。实现规格写入[电脑端规格](03-pc-implementation.md)与[界面规范](06-ui-style-guide.md)。

## UX-005 · 手动地址校验

**当前缺口**：界面仅按非空允许提交，提交后立即收起输入框；非法 IPv4 在更深层选路时才被过滤，容易被误认为连接故障。

**完成标准**：复用严格 IPv4 校验，在字段内显示简短错误并保留原输入；非法地址不启动连接。有效提交后再收起输入区域和键盘，按钮与键盘完成键行为一致。不扩展为尚未设计的域名或 IPv6 支持。

**验收**：空白、首尾空格、缺段、越界数字、字母、粘贴和合法地址；同时覆盖按钮和键盘提交，错误修正后可正常连接。

**涉及位置**：[手动输入界面](../android/app/src/main/java/com/blueaudiosink/sender/ui/SenderScreen.kt)、[连接入口](../android/app/src/main/java/com/blueaudiosink/sender/core/LinkController.kt)、[IPv4 校验](../android/app/src/main/java/com/blueaudiosink/sender/net/bas2/RoutePlanner.kt)。实现规格写入[手机端规格](04-android-implementation.md)。

## UX-006 · 权限拒绝后的恢复

**当前缺口**：运行权限请求失败后仅提示授权，系统不再弹出授权窗时，缺少引导用户进入应用权限设置的分支。

**完成标准**：区分首次请求、可再次请求与需要前往系统设置的情况，按实际缺失权限说明原因并提供设置入口。返回应用后重新核对，不无限重复请求，不伪报已授权；采集授权仍由用户在系统对话框确认。

**验收**：首次拒绝、多次拒绝、不再弹窗、进入设置授权/撤销、取消采集授权、旋转及后台返回；按 Android 版本覆盖录音与通知权限差异。测试不得遗留用户权限修改。

**涉及位置**：[授权流程](../android/app/src/main/java/com/blueaudiosink/sender/MainActivity.kt)、[权限辅助](../android/app/src/main/java/com/blueaudiosink/sender/capture/MediaProjectionHelper.kt)。实现规格写入[手机端规格](04-android-implementation.md)。

## UX-007 · 缓冲挡位偏好记忆

**当前缺口**：挡位只更新进程内状态和运行中采集器，进程重建后默认回到“平衡”。

**完成标准**：保存并恢复用户选择的挡位，非法或缺失值使用默认值；沿用现有发送边界应用与确认机制。不持久化连接会话、采集授权或待应用标记。

**验收**：三挡分别冷启动、进程回收后恢复；升级无配置、损坏配置及发送中切换也正确，不增加重复采集或重启授权。

**涉及位置**：[状态默认值](../android/app/src/main/java/com/blueaudiosink/sender/core/UiState.kt)、[挡位控制](../android/app/src/main/java/com/blueaudiosink/sender/core/LinkController.kt)。实现规格写入[手机端规格](04-android-implementation.md)。

## UX-008 · 删除撤销与触控边界

**当前缺口**：记忆设备直接删除，没有撤销机会；删除入口显式布局为 32dp，与可点击设备行相邻，实际触控边界还需核对 Compose 的扩展行为。

**完成标准**：保持图标视觉尺寸，提供清楚且不与连接动作混淆的触控区；删除后通过短提示提供撤销。撤销恢复原设备身份与地址历史，不能覆盖期间的新记录，也不能擅自发起连接。不增加每次删除必弹的重复确认窗。

**验收**：误触、连续删除不同设备、撤销、提示超时、删除当前设备、期间重新发现同一电脑及后台返回；核对触控、TalkBack、连接状态和记录归并。

**涉及位置**：[设备列表与删除入口](../android/app/src/main/java/com/blueaudiosink/sender/ui/SenderScreen.kt)、[设备记录](../android/app/src/main/java/com/blueaudiosink/sender/core/SavedDeviceStore.kt)。实现规格写入[手机端规格](04-android-implementation.md)与[界面规范](06-ui-style-guide.md)。

## UX-009 · 电脑控件无障碍语义

**当前缺口**：GDI 自绘交互区域缺少辅助技术可识别的控件树。现有 Tab/F1 操作不能代替读屏支持。

**完成标准**：保留 Win32/GDI 技术栈和视觉风格，为按钮、开关、标签、输入及状态提供正确的名称、角色、值、选中/禁用状态、焦点和适用操作模式；状态变更及时通知辅助技术，不暴露已隐藏页面的操作。

**验收**：UI Automation 枚举可识别当前可见控件；Narrator 可按顺序完成模式导航、设置、连接、开关、音量输入和退出。鼠标、键盘、托盘恢复及已有焦点提示无回归。

**涉及位置**：[主窗口与自绘交互](../src/SinkLite/Ui/MainWindow.cs)、[原生接口](../src/SinkLite/Platform/Win32.cs)。实现前补充[电脑端规格](03-pc-implementation.md)中的 provider 生命周期、控件标识及线程边界，并同步[界面规范](06-ui-style-guide.md)。

## UX-010 · 配置中断保护

**当前缺口**：直接覆盖写入配置，存在保存过程中异常退出或磁盘故障导致文件不完整的风险；这不是已完成的断电实机故障验证。

**完成标准**：完整配置通过同目录临时文件与原子提交替换，保留可恢复的上一份有效配置；失败时不破坏现有有效配置，启动能识别并处理损坏文件。继续使用后台合并写入与明确失败反馈，补充临时文件和备份的清理规则。

**验收**：模拟写入/刷新/替换各阶段失败、文件占用、无写权限、损坏主文件和备份；核对最新完整快照、恢复结果与提示，不能无声重置所有设置。不得在用户实际配置上做破坏性注入。

**涉及位置**：[配置读写](../src/SinkLite/Platform/Settings.cs)、[后台设置写入](../src/SinkLite/Platform/SettingsWriter.cs)。实现规格写入[电脑端规格](03-pc-implementation.md)，测试方法同步[验收规范](05-testing-acceptance.md)。
