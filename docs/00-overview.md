## 当前产品范围

本项目中文名为“蓝音频”，英文全称“BlueAudioSink”，简称“BAS”。它是 MIT 开源的 Android → Windows 音频工具，作者 liubaiqing。双端关于页展示这三种名称；Android桌面名称在中文系统下为“蓝音频”，其他语言为“BlueAudioSink”，不在桌面名称中附加“发送端”。
- 蓝牙模式通过 Windows A2DP 接收手机音频，手机无需安装发送端。
- Wi-Fi 模式使用 Android 发送端，在同一局域网内传输 PCM；普通用户不需要 USB 或无线调试。
- 电脑端统一设置播放输出、连接手机、启动偏好和可选防火墙放行；两种模式互斥。
- Wi-Fi 可选 WASAPI 独占输出，默认共享；独占切换先静音，实际输出模式与回退原因可见。蓝牙仍由系统播放。
- 手机按电脑固定身份记忆与主动寻址，同一电脑不同网络地址合并；旧地址记录显式确认迁移，不按同名自动合并。
- 自动记忆蓝牙/Wi-Fi模式；统一自动连接开关控制启动和切换时的电脑端连接，设置“关于”集中显示版本、作者、项目与MIT协议。
- Android 主界面右上齿轮进入设置，提供音量悬浮窗授权、紧凑主题选项、防误开外放、连接日志、本机信息和关于。发送中可通过通知打开悬浮音量滑条。底部显示丢包率和本次发送时长。
- 设置支持自定义全局快捷键：断开所有连接、重连当前模式、调高/调低Wi-Fi音量；冲突提示用户更换，不自动改键。
- 可选择关闭窗口时缩小到托盘，保持当前音频链路。托盘显示当前模式及连接状态，提供打开和彻底退出。
- 不提供多手机混音、互联网中继或加密传输。Android 应用禁止被捕获的音频无法强制获取。

## 文档维护规则

增加功能前，先修改对应规格、明确模块职责、状态语义、失败路径和验收条件，再实现代码。实现改变设计时同步调整规格，不在文末累计过程记录。删除功能时同步移除其规格和无效引用。测试结果应保存在本地 artifacts 或 CI 产物中；本目录仅保留测试方法与尚未验证的边界，不把局部测试写成普遍保证。

涉及界面变更时先阅读[双端界面规范](06-ui-style-guide.md)，并在对应端规格中记录新增行为。控件、样式与 UI 技术栈统一由界面规范维护。

待完成的体验改进统一维护于[使用体验清单](08-ux-backlog.md)。任务完成后同步当前实现规格与验收条件，再更新清单状态；清单不承载开发日志，也不将待实现目标写成已有能力。

## 开发方向

优先补齐[使用体验清单](08-ux-backlog.md)中的状态一致性、取消路径、后台任务退出交接及操作反馈，后续持续登记和完成已确认的体验改进。

优先验证长时间运行的设备时钟漂移、弱网恢复、不同 Android 后台限制及两台实体手机切换。继续改善自绘界面的辅助技术支持。异步采样率校正、编码协商、互联网连接均未实现；如推进，须先另行确定规格，涉及协议则同步两端。
