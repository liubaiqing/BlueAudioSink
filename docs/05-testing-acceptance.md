# 测试与验收标准

本文是可重复的验收方法，不是历史运行记录。结果、日志、录音和截图保存在本地忽略的 artifacts 或 CI 产物中，注明测试版本、设备及条件。

## 自动检查

```powershell
dotnet run --project tools/AudioRegression -c Release
dotnet run --project tools/FirewallRegression -c Release
dotnet publish src/SinkLite/SinkLite.csproj -c Release -p:Platform=x64 -o artifacts/pc --nologo
./android/gradlew.bat -p android assembleRelease --console=plain
```

音频回归覆盖健康 PCM 不变、真实欠载/补零、恢复阈值、排空、乱序/缺包/迟到、来源切换与隔离、状态映射与托盘原生 Shell 注册/更新/移除、图标句柄释放（需要交互桌面）。防火墙使用隔离存储测试写操作，系统仅只读检测；真实提权写入和取消需单独人工验收，不在日常自动测试修改用户规则。

## 设置界面验收

在默认和最小窗口及不同 DPI 下，核对窄侧栏与内容区无重叠；分类、设备类型标签、开关与下拉绘制位置和点击命中一致。单页不显示也不响应分页。设备名可通过悬停完整查看。

功能说明悬停 550ms 后显示并自动换行，窗口四边不裁切；移开、点击、切换页面、失焦或缩小托盘时关闭。Tab 聚焦后 F1 显示帮助，Escape 先关闭帮助，随后才关闭下拉或设置。实际状态、错误与防火墙操作结果保持可见。预览工具以示例数据运行产品实际 GDI 绘制，仅替代布局检查，不冒充真实窗口的鼠标操作验收。

## 模式记忆、自动连接与关于

- 分别选择蓝牙/Wi-Fi后重启，恢复所选模式；进入设置不改变已保存模式，不提供额外记忆开关。
- 关闭自动连接后，重启和切换模式都不主动连接；Wi-Fi不监听发现或音频端口。
- 开启后，蓝牙请求首选设备连接，Wi-Fi启动监听等待手机；入口只执行一次。Wi-Fi启动失败保留原模式与可操作错误。显式CLI --wifi仍可主动启用。
- 修改自动连接开关只保存偏好，不打断或强制开启当前会话；原有autoconnect配置继续有效。
- 关于页显示实际程序集版本、liubaiqing、MIT License、项目地址与图标；项目和协议按钮打开固定官方仓库链接。检查最小窗口、DPI、Tab/Enter命中，其他页不重复显示版本和作者。

## 托盘验收

- 新配置默认关闭：关闭窗口结束进程；开启并重启仍保留偏好。
- 默认/最小窗口设置不重叠，开关鼠标与 Tab/Space 均可操作，焦点清晰。
- 开启后关闭窗口从任务栏隐藏，音频仍接收；普通最小化不隐藏至托盘。
- 单击/键盘激活及“打开主界面”恢复原页面；重复运行 exe 恢复同一进程。
- 右键严格两个选项，点外部取消；“彻底退出”即使开关开启也结束进程并移除图标。
- 注入 Wi-Fi HELLO、START/AUDIO、静音、断流、恢复、STOP，核对图标及 tooltip 对应状态；切换蓝牙/设置时显示当前音频模式，无过期状态。
- Explorer 重建后重新注册图标；注册失败不隐藏成无法恢复的进程。系统注销/关机不受缩小托盘设置阻拦。
- 多次隐藏/恢复、开启/关闭，观察 GDI/USER 句柄不持续增长。退出后 UDP 端口可重新绑定。

## 端到端音频

同一局域网运行真实 Android 发送端与 PC。确认发现/手动 IP、授权、实际播放、静音、停止排空、重启会话、输出设备变化及两台实体手机切换。正常结束排空不计欠载；断流/补零必须如实统计。

对相同曲目的稳定片段录制 Windows WASAPI 回环，与输入波形对齐，结合 received/missing/late、underruns、outputPaddingFrames、outputOverflows 和输入零帧诊断定位问题；只听到声音或一段无断点录音不能证明所有网络条件稳定。延迟用实际端到端测量，RTT 不充当单程听感延迟。

长期测试至少覆盖 30 分钟连续播放、不同输出设备与 2.4/5 GHz 网络，观察缓冲漂移及内存；设备时钟漂移校正尚未实现。UDP 集成测试不代替两台实体手机或真实系统音频验收。

## 发布与隐私

确认 Windows 启动/单实例、资源图标、双端作者署名、Android 正式签名及版本码。README 链接和图片应存在；公开截图遮挡 IP、设备身份与状态栏等隐私。候选构建通过后再同步正式文件并更新对应 SHA256SUMS，不因本地测试自动更新线上 Release。

## WASAPI 输出验收

音频回归覆盖输出默认共享/100% 软件音量、启用独占置 0、关闭不增大音量、增益 0/100% 和平滑变化、16→24/32 位扩展、显式端点、独占初始化/开始失败后的单次共享回退、全部失败及原生资源释放；独占启动需覆盖两块设备缓冲、取消不消费数据、短有限流正常排空。测试后端隔离，不在单测修改用户配置。

`tools/AudioRegression --exclusive-probe [endpointId]` 用软件静音检查真实独占、第二客户端被拒和释放后共享重开；会短暂占用目标设备。`--output-flow [endpointId]` 监听产品 UDP 端口并等待真实发送端，在 0% 音量下切换共享→独占→共享，核对模式快照及静音状态；测试前退出产品避免端口冲突。不得把软件音量调成 0 的占用测试声称为音质或听感验收。

发布包需验证裁剪后仍能创建独占端点，配置临时切换时在 finally 恢复原始字节与正常接收。实际设备关闭独占权限、拔出、系统休眠、不同位深硬件及持续弱网为兼容性验收项；共享失败不得显示“已独占”。

独占连续性验收使用同一段已解码 PCM、相同软件增益与实时供包节奏，通过产品输出链核对无缺数、无补静音、无溢出且送入 WASAPI 的样本哈希一致。独占事件模式为双缓冲，首次 Read 前应按实际块长准备两块数据及余量，不能只凭配置的网络缓冲下限开始播放。测试工具参数与证据边界见 tools/AudioRegression/README.md。供数间隔和应用计数不能替代 DAC 输出录音或用户同源试听

远程音量验收：同源读写与电脑主动通知、UI双端同步、旧版电脑禁用滑条、失联和重连不重放、重复/乱序幂等、PC本地静音拒绝旧调高、其他来源端点与过期PONG拒绝、0/100边界、拖动合并并最终提交。真实UDP隔离测试不启动播放器；手机交互核验仅降低音量并恢复原值，不提高手机/系统总音量

音量交互验收：未连接隐藏手机音量卡、连接后在缓冲档位下方显示；PC数字点击/Tab进入原位输入，Enter提交、Esc取消、越界与非整数不修改设置，±及手机入口仍同步。手机远程变更时取消PC未提交草稿，尺寸/DPI变化及窗口关闭时释放编辑控件

全局快捷键验收：默认未绑定；录入/取消/清除/持久化，Ctrl/Alt/Shift及方向键和功能键格式，内部重复/系统占用提示且不改原绑定，启动注册失败显示未生效，清除/退出释放注册，旧WM_HOTKEY不得误执行新绑定。录入期间实际占用的外部组合也应能提示冲突且不触发外部动作，结束/失焦卸载录入钩子；常态不运行该钩子。真实其他窗口前台和托盘时调音量、断开与当前模式重连，Wi-Fi重连不擅自获取手机采集授权；测试只降低音量再恢复原值，临时组合结束后清除

Wi-Fi启用/断开验收：开启后等待真实手机响应，已启用时启用按钮禁用、断开可用，关闭时反向；断开后控制/音频UDP端口均释放、播放器与发现停止，后续手机包不能使接收自动开启；重新启用/快捷键重连可恢复。最小窗口检查指标下按钮、地址行、展开详情和底部提示均不遮挡；悬停明确手机需要自行点击“开始发送”的条件
