# Android 实现规格

视觉、控件和 UI 技术栈遵循[双端界面规范](06-ui-style-guide.md#android-发送端)。本页描述手机端的功能行为与实现约束。

包名 `com.blueaudiosink.sender`，Android 10+，Kotlin/Compose。MainActivity 提供电脑选择、手动 IP、缓冲档位、录音授权和开始/停止；底部显示丢包率和发送时长。普通使用不需要开发者设置或 ADB。

## 设置与信息呈现

局域网 UDP 优先绑定具备 IPv4 地址的非 VPN Wi-Fi 或以太网 Network，发现、身份查询、音频和诊断共用该套接字。存在未被这些 Network 覆盖的局域网接口（例如手机同时开热点）时，使用系统局域网路由，以免绑定上游 Wi-Fi 后屏蔽热点下游。物理接口变化时重建通道并验证电脑身份。枚举排除 VPN、隧道和蜂窝接口。Android VPN 禁止绕过或锁定模式可能阻止物理网络通信，需要用户在 VPN 中允许局域网或排除蓝音频，应用不能承诺绕过系统限制。

「连接日志」位于功能设置与本机信息之间。手机在 App 私有存储保留最近 96 条结构化事件，确认连上支持诊断同步的电脑后分批上传，收到确认才标记已同步。未连接时仍可通过系统文件保存对话框导出最近事件。日志仅含应用事件和数值统计，不采集音频、系统 logcat 或其他 App 数据。

Wi-Fi 首次确认连接或掉线后重新确认连接时，将手机媒体音量调到 0。该操作不依赖无障碍授权，也不改变蓝音频的电脑接收音量。「防误开外放」默认关闭，开启并授权蓝音频的无障碍服务后，仅在正在发送且电脑在线时拦截物理音量加键。停止、掉线或关闭选项后解除拦截，媒体音量保留当前值。服务不读取屏幕内容。系统音量面板、系统组合键和其他无障碍服务可能绕开按键拦截。

主界面右上角提供简约齿轮图标，48dp 触控区，辅助描述“设置”。设置依次显示音量悬浮窗、主题、本机信息、关于。本机信息和关于始终为最后两项。主题行右侧并排放置三个紧凑的单选项，默认跟随系统，也可直接点选浅色或深色。选择即时应用并持久保存。应用页面和悬浮窗共用该偏好。信息页通过顶部返回或系统返回逐级退出。页面和主题切换不停止发现、连接或采集。

本机信息显示设备制造商/型号、Android版本、当前局域网IPv4地址；地址在详情页可见时每秒刷新，无地址显示“未连接局域网”，不读取序列号或MAC。关于显示应用图标、中文名“蓝音频”、英文全称“BlueAudioSink”、简称“BAS”、Android发送端、实际安装版本、开发作者liubaiqing、MIT License、项目地址和版权信息；项目主页和协议可打开浏览器。主界面不再显示作者署名。桌面名称使用独立语言资源：中文为“蓝音频”，默认语言为“BlueAudioSink”。

发送时长采用单调时钟，累计本次发送中音频发送闸门开放的时间，格式为mm:ss，满一小时为hh:mm:ss。网络切换、身份重新寻址或停止时暂停，恢复后续计；停止保留数值，下次开始发送归零。每秒刷新界面，不按包数估算，也不代表电脑实际播放时长。包数仍供内部诊断。

## 采集与发送

LinkController 管理应用连接状态及唯一 UdpSender。AudioCaptureService 持有 mediaProjection 前台服务，使用 AudioPlaybackCapture / AudioRecord 获取允许被捕获的应用音频。权限包含录音、屏幕/音频捕获授权，通知权限按系统版本处理。停止/撤销授权必须释放录音和投屏资源。

PcmRecorder 将 PCM 放入环形缓冲并按 5 ms 打包。短读继续攒满 960 字节；环空等待真实采集，不伪造连续序号静音。真实静音照常发送。发送失败消耗源序号并计数；采样时间戳与控制时间戳统一为 BOOTTIME/elapsedRealtimeNanos 时基。缓冲档位用于发送端稳定性取舍，不改变线格式。

## 连接与限制

发现监听 OFFER 并按电脑 IP 去重，6 秒未见自动过期；可手动输入地址。开始前 HELLO 后 START，停止时 STOP；选定电脑时持续回应其 PING。切换电脑先停止当前发送。

部分应用禁止内部音频捕获；捕获授权成功不意味着所有内容都可收音。PONG 只能证明控制路径，不能证明 PC 已经收到 AUDIO 或实际出声。Wi-Fi/后台权限变化时应明确提示重试，不宣称无条件自动恢复。

## 构建与签名

工程位于 android/，使用仓库固定 Gradle wrapper、AGP/Kotlin 版本和 JDK 21，SDK 路径由本地环境提供。

```powershell
./android/gradlew.bat -p android assembleRelease --console=plain
```

复制 android/signing.properties.example 为本地忽略的 signing.properties 并配置独立发布密钥；源码无密码。未配置签名时只能产出未签名 Release，不能当作可安装正式包。当前本地版本 versionName=0.2.16、versionCode=20，产物 artifacts/BlueAudioSink-Sender-0.2.16.apk。更新必须沿用发布密钥并递增版本码；旧测试签名安装无法直接覆盖，需卸载后安装（会清空记忆设备）。

发布前运行 apksigner 验证证书与签名，检查无 debuggable。密钥及凭据仅由维护者离线备份，不提交到仓库。

## 电脑接收音量

首次使用通知调音量时，在手机设置的“音量悬浮窗”中开启 Android 的“在其他应用上层显示”权限。发送中点按通知正文或“调节音量”，由采集服务显示可触摸且不抢焦点的音量悬浮窗。若系统保留通知栏，收起后可操作滑条。音量与主界面共用，连接中断或未同步时禁止调整，结束发送时移除悬浮窗。

悬浮窗与手机主界面共用 Compose 的 ReceiverVolumeControl 和 BlueAudioSinkTheme，滑条轨道、滑块和百分比由同一组件绘制。悬浮窗口持有独立的 LifecycleOwner 和 SavedStateRegistryOwner，关闭时释放 Compose 内容。

缓冲档位下、开始发送按钮上提供0–100%连续滑条和百分比，控制电脑Wi-Fi软件增益，不调整手机媒体音量或电脑总音量。未确认连接时整块隐藏；最近PING确认连接后显示，无新鲜音量状态/旧电脑端时禁用并简短显示等待或需更新电脑端；收到权威值后才可编辑。手势中显示本地拖动值，单在途控制器合并/限频并在松手保留最终值；每秒GET纠正状态，切换目标/断线清空待发意图。电脑本地修改和独占置零同步回显，冲突时以电脑状态为准，不额外申请权限

手机连接确认单独依据既有PING新鲜度（5秒），即使采集仍在运行，控制链失联也隐藏音量区域；这不改变采集服务的后台运行机制

## 按电脑身份保存与重连

保存记录按deviceId合并，名称仅显示，历史地址最多8个且只作寻址线索；同名不同ID不能合并，同IP不同ID不能覆盖。首个有效身份握手并收到PING后保存，普通OFFER不落盘。列表合并发现和记忆按ID，只显示一台电脑；无ID的旧记录仍按地址保留，并要求首次确认，不能靠名称推断身份。

当前已连接电脑提供“合并旧地址”入口，由用户明确选取无ID记录，确认后将历史地址并入当前身份并删除所选旧条目；不会吞并已有其他ID的电脑。删除整台电脑即删除其地址历史，不因后续广播自动复活。最多保存5台已识别电脑；迁移期间额外保留最多5条无身份旧记录，避免新增身份时提前淘汰待合并旧地址。最近使用仅在真实连接成功时更新，地址/名称更新不伪造使用时间。

界面增加“正在查找电脑”状态，显示电脑名称，IP仅在需要时作为次要信息。查找期间禁止开始发送；同一身份多网卡优先维持当前新鲜连接，无新鲜连接时对可达候选验证，首个有效回应获选，不被后续另一接口OFFER来回切换。身份标识用于避免误连，不宣称局域网防冒充或加密。

已选择电脑身份时，Activity进入后台只停止列表展示维护，保留控制socket和寻址意图，避免授权弹窗/切换网络设置破坏握手；断开或无目标时释放。已有采集仍由前台服务负责，系统后台网络限制仍适用。

## 设备列表呈现

设备列表上方放置“手动添加”和48dp触控区的圆形回转箭头刷新图标，刷新具有“刷新”辅助技术描述；手动输入框紧随操作行展开，设备条目在其下方。条目仅显示电脑名称、选择状态、最近使用和删除入口，不显示IP或端口；缺少名称的已保存/旧记录显示“已保存的电脑”，其他设备显示“未命名电脑”。地址仍作为内部寻址数据，手动输入与明确的旧记录确认/合并弹窗保留必要地址，避免误合并。刷新不触发采集授权，不改变已选电脑身份。
