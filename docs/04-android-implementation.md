# Android 实现规格

BAS2 连接行为与边界见 [连接层实现](07-bas2-connection-design.md)。双端正式应用入口均使用 BAS2。

视觉、控件和 UI 技术栈遵循[双端界面规范](06-ui-style-guide.md#android-发送端)。本页描述手机端的功能行为与实现约束。

包名 `com.blueaudiosink.sender`，Android 10+，Kotlin/Compose。MainActivity 提供电脑选择、手动 IP、缓冲档位、录音授权和开始/停止；底部显示丢包率和发送时长。普通使用不需要开发者设置或 ADB。

## 设置与信息呈现

局域网发现与验证后的会话分别拥有网络资源。普通 Wi-Fi/以太网路径绑定对应非 VPN Network；热点接口无 Network 时使用系统路由，并用实际本地 IPv4 约束后续通道。会话保留健康路径，不因无关接口变化重建。Android VPN 禁止绕过或锁定模式可能阻止物理网络通信，需要用户在 VPN 中允许局域网或排除蓝音频，应用不能承诺绕过系统限制。

「连接日志」位于功能设置与本机信息之间。诊断后台维护最近7天、2 MiB、4096条事件，任一达到即轮转。确认连接后，通过关联当前会话的独立TCP诊断连接分批上传，电脑落盘确认后才标记同步。未连接时仍可通过系统文件保存对话框导出快照。日志仅含应用事件和数值统计，不采集音频、系统 logcat 或其他 App 数据。

Wi-Fi 首次确认连接或掉线后重新确认连接时，将手机媒体音量调到 0。该操作不依赖无障碍授权，也不改变蓝音频的电脑接收音量。「防误开外放」默认关闭，开启并授权蓝音频的无障碍服务后，仅在正在发送且电脑在线时拦截物理音量加键。停止、掉线或关闭选项后解除拦截，媒体音量保留当前值。服务不读取屏幕内容。系统音量面板、系统组合键和其他无障碍服务可能绕开按键拦截。

主界面右上角提供简约齿轮图标，48dp 触控区，辅助描述“设置”。设置依次显示音量悬浮窗、主题、防误开外放、连接日志、本机信息、关于。本机信息和关于始终为最后两项。主题行右侧并排放置三个紧凑的单选项，默认跟随系统，也可直接点选浅色或深色。选择即时应用并持久保存。应用页面和悬浮窗共用该偏好。信息页通过顶部返回或系统返回逐级退出。页面和主题切换不停止发现、连接或采集。

本机信息显示设备制造商/型号、Android版本、当前局域网IPv4地址；地址在详情页可见时每秒刷新，无地址显示“未连接局域网”，不读取序列号或MAC。关于显示应用图标、中文名“蓝音频”、英文全称“BlueAudioSink”、简称“BAS”、Android发送端、实际安装版本、开发作者liubaiqing、MIT License、项目地址和版权信息；项目主页和协议可打开浏览器。主界面不再显示作者署名。桌面名称使用独立语言资源：中文为“蓝音频”，默认语言为“BlueAudioSink”。

发送时长采用单调时钟，累计本次发送中音频发送闸门开放的时间，格式为mm:ss，满一小时为hh:mm:ss。网络切换、身份重新寻址或停止时暂停，恢复后续计；停止保留数值，下次开始发送归零。每秒刷新界面，不按包数估算，也不代表电脑实际播放时长。包数仍供内部诊断。

## 采集与发送

运行中修改缓冲档位实时交由发送线程应用，不重建MediaProjection或AudioRecord。环形存储固定容纳最大档位的上限；提高档位在发送边界有限等待预填，降低档位不删健康PCM以强追延迟。UI跟踪请求与应用确认，等待期间只显示短状态。内部包计数不逐包驱动页面，发送时长按秒更新。通知仅订阅连接/采集阶段变化，重连时显示恢复状态，不能把授权仍有效误报为正在发送。

设备发现展示使用单个串行执行器与可见性代际管理，Activity前后台不创建裸线程，旧任务不得复活已停止列表。刷新调用现有发现服务的立即查询，不清空设备。日志单所有者后台线程维护7天/2MiB/4096条有界队列，增量计字节，批量持久化；UI记录只排队，批次和导出读取不可变快照。非关键日志上传采用独立控制连接，同实例/同会话代际校验，不能占用调音命令队列或拖慢心跳。

LinkController管理应用状态，Bas2Sender组合NetworkEnvironment、LanDiscovery与SessionCoordinator，ControlConnection负责验证后的TCP控制及UDP/TCP媒体。AudioCaptureService 持有 mediaProjection 前台服务，使用 AudioPlaybackCapture / AudioRecord 获取允许被捕获的应用音频。权限包含录音、屏幕/音频捕获授权，通知权限按系统版本处理。停止/撤销授权必须释放录音和投屏资源。

PcmRecorder 将 PCM 放入环形缓冲并按 5 ms 打包。短读继续攒满 960 字节；环空等待真实采集，不伪造连续序号静音。真实静音照常发送。发送失败消耗源序号并计数；采样时间戳与控制时间戳统一为 BOOTTIME/elapsedRealtimeNanos 时基。缓冲档位用于发送端稳定性取舍，不改变线格式。

## 连接与限制

发现元数据按稳定电脑ID归并，6秒未见自动过期；可手动输入IPv4。TCP身份核对与媒体双向验证后才显示已连接。串行会话执行器管理开始、停止、心跳和重连；最多3条候选竞争，保留健康路径，明确断开取消恢复。采集授权有效时换网不重弹授权。

部分应用禁止内部音频捕获；捕获授权成功不意味着所有内容都可收音。TCP心跳只证明控制路径；音频接收确认与实际输出分别判断。Wi-Fi/后台权限变化时应明确提示重试，不宣称无条件自动恢复。

## 构建与签名

工程位于 android/，使用仓库固定 Gradle wrapper、AGP/Kotlin 版本和 JDK 21，SDK 路径由本地环境提供。

```powershell
./android/gradlew.bat -p android assembleRelease --console=plain
```

复制 android/signing.properties.example 为本地忽略的 signing.properties 并配置独立发布密钥；源码无密码。未配置签名时只能产出未签名 Release，不能当作可安装正式包。当前版本 versionName=0.3.1、versionCode=23，产物 artifacts/BAS2-final/BlueAudioSink-Sender-0.3.1.apk。更新必须沿用发布密钥并递增版本码；旧测试签名安装无法直接覆盖，需卸载后安装（会清空记忆设备）。

发布前运行 apksigner 验证证书与签名，检查无 debuggable。密钥及凭据仅由维护者离线备份，不提交到仓库。

## 电脑接收音量

首次使用通知调音量时，在手机设置的“音量悬浮窗”中开启 Android 的“在其他应用上层显示”权限。发送中点按通知正文或“调节音量”，由采集服务显示可触摸且不抢焦点的音量悬浮窗。若系统保留通知栏，收起后可操作滑条。音量与主界面共用，连接中断或未同步时禁止调整，结束发送时移除悬浮窗。

悬浮窗与手机主界面共用 Compose 的 ReceiverVolumeControl 和 BlueAudioSinkTheme，滑条轨道、滑块和百分比由同一组件绘制。悬浮窗口持有独立的 LifecycleOwner 和 SavedStateRegistryOwner，关闭时释放 Compose 内容。

缓冲档位下、开始发送按钮上提供0–100%连续滑条和百分比，控制电脑Wi-Fi软件增益，不调整手机媒体音量或电脑总音量。未确认连接时整块隐藏；BAS2验证就绪后显示，无新鲜音量状态/旧电脑端时禁用并简短显示等待或需更新电脑端；收到权威值后才可编辑。手势中显示本地拖动值，串行控制器合并待发送值并在松手保留最终值；每2秒通过控制通道GET同步状态，切换目标/断线清空待发意图。电脑本地修改和独占置零同步回显，冲突时以电脑状态为准，不额外申请权限

手机连接依据已验证的BAS2会话与控制心跳新鲜度，即使采集仍在运行，控制链失联也隐藏音量区域；这不改变采集服务的后台运行机制

## 按电脑身份保存与重连

保存记录按deviceId合并，名称仅显示，历史地址最多8个且只作寻址线索；同名不同ID不能合并，同IP不同ID不能覆盖。TCP身份与媒体路径验证成功后保存，普通OFFER不落盘。列表合并发现和记忆按ID，只显示一台电脑；无ID的旧记录仍按地址保留，并要求首次确认，不能靠名称推断身份。

当前已连接电脑提供“合并旧地址”入口，由用户明确选取无ID记录，确认后将历史地址并入当前身份并删除所选旧条目；不会吞并已有其他ID的电脑。删除整台电脑即删除其地址历史，不因后续广播自动复活。最多保存5台已识别电脑；迁移期间额外保留最多5条无身份旧记录，避免新增身份时提前淘汰待合并旧地址。最近使用仅在真实连接成功时更新，地址/名称更新不伪造使用时间。

界面增加“正在查找电脑”状态，显示电脑名称，IP仅在需要时作为次要信息。查找期间禁止开始发送；同一身份多网卡优先维持当前新鲜连接，无新鲜连接时对可达候选验证，首个有效回应获选，不被后续另一接口OFFER来回切换。身份标识用于避免误连，不宣称局域网防冒充或加密。

已选择电脑身份时，Activity进入后台只停止列表展示维护，保留控制socket和寻址意图，避免授权弹窗/切换网络设置破坏握手；断开或无目标时释放。已有采集仍由前台服务负责，系统后台网络限制仍适用。

## 设备列表呈现

设备列表上方放置“手动添加”和48dp触控区的圆形回转箭头刷新图标，刷新具有“刷新”辅助技术描述；手动输入框紧随操作行展开，设备条目在其下方。条目仅显示电脑名称、选择状态、最近使用和删除入口，不显示IP或端口；缺少名称的已保存/旧记录显示“已保存的电脑”，其他设备显示“未命名电脑”。地址仍作为内部寻址数据，手动输入与明确的旧记录确认/合并弹窗保留必要地址，避免误合并。刷新不触发采集授权，不改变已选电脑身份。

## 手机音量和系统限制

每次新连接确认后将手机媒体音量归零，不修改电脑权威接收音量。防误外放开关通过已授权的辅助功能拦截媒体调高，未开启时允许用户随后自行调节媒体音量；不把它表述为系统级绝对静音保证。原生采集授权的系统共享提示不能由应用隐藏。

普通Wi-Fi/以太网使用对应Android Network；热点接口即使没有Network也列入候选，按实际本地地址约束后续通道。VPN拒绝绑定时记录系统证据并提示局域网放行或绕过策略，不能承诺无权限绕过强制VPN。
